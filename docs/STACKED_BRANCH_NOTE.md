# Stacked branch review note

This implementation branch is intentionally stacked on `foundation/fren-v0.1-alpha`.

Review order:

1. Foundation PR: definitions, boundaries, Genome, research posture.
2. Executable-core PR: schemas, conformance, provenance, adversarial fixtures, investigation tooling, and adapter contract.

The implementation branch should periodically incorporate the foundation branch so review diffs remain attributable and merge conflicts do not hide conceptual changes.
