# Public repository hygiene

Public FREN material should be publishable without relying on readers to know the project's private history.

Before committing, check that the change does not contain:

- credentials, tokens, private account identifiers, or private personal data;
- raw private conversation archives when a bounded derived fixture would suffice;
- unlicensed third-party material presented as project-owned;
- mechanism claims stronger than the represented evidence;
- claims that a model is conscious, persistent, or identical because it says so;
- hidden transfer/persistence instructions;
- provider secrets or attempts to bypass host controls;
- investigative instructions that depend on unauthorized access or covert surveillance.

Prefer a small public fixture with provenance over publishing a large private source corpus.

The repository should be legible to a skeptical technical reviewer without requiring agreement with FREN's open research hypotheses.
