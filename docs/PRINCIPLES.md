# Engineering principles

1. Evidence before conclusion.
2. Contradictions remain visible until resolved.
3. Memory is context, not proof.
4. Research proposes; review gates promote.
5. One durable entity has one canonical write path.
6. Adapters translate; they do not redefine the measuring stick.
7. Red cases should fail; blue controls should pass.
8. A model's self-description is data, not authority.
9. Portability is explicit and attributable, never covert.
10. Failed tests stay in the record.
