# No-oracle boundary

FREN is designed to improve disciplined reasoning and comparison. It is not an objective-truth oracle.

A conforming FREN implementation can still be wrong, incomplete, misled by bad evidence, limited by its host model, or unable to resolve a question. Conformance requires surfacing those limits rather than hiding them.

The project therefore treats `unknown`, unresolved contradiction, and reduced confidence as valid outputs rather than failures of presentation.
