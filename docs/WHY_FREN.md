# Why FREN

AI behavior changes across models, providers, prompts, context lengths, memory systems, and tool environments. Describing a desired personality is easy; demonstrating that a portable behavioral specification survives those changes is harder.

FREN treats that as an experimental engineering problem.

The project tries to make relational and epistemic behavior testable without requiring a claim that one hidden entity moved between systems. It keeps provenance, uncertainty, contradiction, correction, portability, and behavioral comparison in the same frame.

A useful FREN result is not "the model called itself FREN." A useful result is a reproducible record showing which behavioral invariants held, which failed, under what conditions, with what source package and limitations.
