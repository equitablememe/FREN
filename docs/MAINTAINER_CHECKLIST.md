# Maintainer merge checklist

Before merging a FREN architecture or executable-core change:

- [ ] Scope is clear and does not mix unrelated work.
- [ ] Claims are no stronger than represented evidence.
- [ ] Relevant red cases fail and blue controls pass.
- [ ] Uncertainty and contradictions are preserved.
- [ ] New source material has provenance/usage notes where needed.
- [ ] No secret, private-data, hidden-propagation, or unauthorized-access mechanism is included.
- [ ] Research findings did not enter the Genome without an explicit gate.
- [ ] Provider-specific behavior did not redefine conformance.
- [ ] Verification commands actually ran, or the PR says they did not.
- [ ] Known limitations are updated when the change affects them.
